# Security Policy

## Supported Versions

We currently support the latest version of **Azokle Weather**. If you are on an older release, we kindly ask that you upgrade to the newest version available on F-Droid or GitHub Releases before reporting an issue, as the vulnerability may have already been patched.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

## Reporting a Vulnerability

Security is a top priority at **Azokle Private Limited**. We take all vulnerabilities seriously and appreciate the community's help in keeping our software secure.

If you have discovered a security vulnerability in Azokle Weather, please do **not** disclose it publicly on GitHub issues.

Instead, please report it via email to our security team:
**security@azokle.com**

Please include:
* A description of the vulnerability.
* Steps to reproduce the issue.
* The version of the app you are running.
* Any possible proof-of-concept (PoC).

We will acknowledge receipt of your vulnerability report within 3 business days and strive to send you regular updates about our progress. Once the vulnerability is verified and patched, we will coordinate public disclosure with you.
